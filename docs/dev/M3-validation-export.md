## 양성 대조 검증 (M3-1)

**무엇을 확인하나:** 점수 체계가 "알려진 AFP는 높고, 아닌 것은 낮게" 구분하는지, 그리고 IBS 지표가 진짜 IBS와 무작위 표면 패치를 구분하는지다.

1. **시드 vs 무작위 패치:** 시드마다 실제 IBS의 4개 지표를 시드 자신의 무작위 패치 분포(M2-2)와 비교한다. 실제 IBS가 분포 어디에 놓이는지(백분위)를 기록한다.
2. **AFP vs 비-AFP:** 시드 구조와 음성 대조(M0-6)에 같은 파이프라인을 적용한다. 음성 대조에는 IBS 정의가 없으므로 무작위 패치 분포로 비교한다.
3. **종합 점수 순위:** 시드와 음성 대조를 한 표에 놓고 종합 점수 순위를 낸다.

**판정:** 시드가 3~5개뿐이라 통계 검정은 의미가 약하다. 대신 아래를 기준으로 하고, 결과를 있는 그대로 보고서에 적는다. **기준은 결과를 보기 전에 `afp/validation.py`에 고정했다**(구현하면서 이 문서의 초안 기준을 더 구체화했다).

- 비교 방향의 사전 가정: 평면성↓, 격자 편차↓, IBS 면적↑이 "얼음 결합면다움"이다. 소수성 비율은 방향을 가정하지 않아 참고만 한다.
- 시드별 통과: 방향성 지표 3개 중 2개 이상에서, 시드의 IBS 값이 음성 대조(비-AFP) 무작위 패치 분포의 상위 10%(90% 이상보다 낫다)에 든다.
- 합격: 모든 시드 통과. 부분 합격: 시드의 절반 이상 통과. 불합격: 그 미만.
- 불합격이면 점수를 "구조 신뢰도와 ESM 점수 중심의 보조 지표"로만 쓴다고 UI와 보고서에 명시하고, 지표 정의 개선을 v1.x 우선순위 1로 올린다.
- 판정 뒤에 방향을 바꿔 본 분석은 보고서의 "사후 탐색"에 따로 적고 판정과 점수에는 반영하지 않는다(결과에 맞춘 과적합을 막기 위해).

## 설계 후보 품질 회귀 테스트 (M3-2)

- 고정 시드(`rng_seed`), 고정 파라미터로 시드별 N=100 설계를 돌려 `pLDDT ≥ 80`이면서 `RMSD ≤ 2 Å`인 후보 비율을 기록한다.
- 기준선은 M1 수용 기준에서 기록한 값이다. 이후 코드 변경 시 이 비율이 기준선에서 허용 범위(예: ±5%p, 제안값) 이상 벗어나면 테스트가 실패한다.
- PRD 성공 지표(30% 이상)를 통과하지 못하면 원인(시드 유형, 임계값, `max_mutations`)을 분석하고 임계값 정책을 PRD 오픈 이슈에서 다시 논의한다.

## 내보내기 (M3-3)

```
exports/<name>/
  candidates.fasta      # 헤더: >cand_id|mutations|score
  ranking.csv           # 선택한 후보의 전체 지표
  structures/<cand_id>.pdb
  seed.json             # 사용한 시드 정보
  params.json
  versions.json
  README.txt            # 점수 한계 문구, 생성 일시, 재현 방법
```

- 내보낼 후보는 순위 상위 N개 또는 순위표에서 체크한 후보다.
- FASTA에는 실험 대조군으로 **시드 원본 서열**을 반드시 포함한다(`>seed|wildtype`).
- `README.txt`에는 "우선순위 보조 지표이며 실제 TH 예측이 아니다"와 재현 명령을 넣는다.

## 실험팀 전달 패키지 (M3-4)

상위 5~10개 후보를 넘길 때 아래를 함께 제안한다. 실험 설계는 실험팀이 최종 결정한다.

| 항목 | 내용 |
| --- | --- |
| 포함할 대조군 | 시드 원본(양성), 활성이 없다고 알려진 단백질 또는 IBS 잔기를 치환한 변이체(음성) |
| 측정 | IRI(ice recrystallization inhibition, splat assay), 열이력(nanoliter osmometer) |
| 발현 | 숙주와 태그는 실험팀 결정. 개발성 플래그(글리코실화 서열, 홀수 Cys)를 참고 |
| 결과 기록 | 후보 ID, 조건(농도, 완충액), 측정값을 CSV로 기록. v1.x의 결과 업로드와 점수 보정(F-16)이 이 형식을 쓰므로 `cand_id`를 그대로 유지 |

## 구현 기록 (2026-10-12)

**구현 범위:** M3-1 ~ M3-5, M3-7. **M3-6(사용성 테스트)과 실험팀 전달은 사람이 필요해 하지 못했다**(아래 참고).

**M3-1 양성 대조 검증 — 결과는 "불합격"이다.** 사전에 정한 기준으로 판정했고 기준을 결과에 맞춰 바꾸지 않았다.

| 구조 | 시드 통과 | 판정 | 보고서 |
| --- | --- | --- | --- |
| 실험 구조 | 0/3 | 불합격 | [validation-report.md](validation-report.md) |
| ESMFold 예측 구조 (후보 평가와 같은 방식) | 1/3 (TmAFP) | 불합격 | [validation-report-predicted.md](validation-report-predicted.md) |

- **평면성**은 모든 시드에서 비-AFP 무작위 패치와 일관되게 구분되었다(대조 패치보다 나음: 실험 구조 0.91~1.00, 예측 구조 0.94~1.00).
- **IBS 면적**은 가정한 방향(클수록 좋음)이 틀렸다. TmAFP(0.01)와 Type III(0.03)의 IBS는 무작위 패치보다 오히려 면적이 작았다(사후 탐색에서 반대 방향으로는 0.97~1.00). Type I은 방향은 맞지만 구분력이 약했다(0.69~0.72).
- **격자 편차**는 TmAFP(예측 구조 0.95)에서만 통과 수준이었고 Type III는 0.50~0.78, Type I은 쌍이 범위에 없어 계산되지 않았다.
- 시드가 3개뿐이고 두 시드는 IBS 잔기 목록이 불완전(`literature_partial`, `derived`)해 결론을 일반화할 수 없다.
- **결정에 따른 조치:** 점수를 "구조 신뢰도와 ESM 점수 중심의 보조 지표"로만 쓴다고 UI(홈과 순위표 상단 배너), README, 사용자 가이드에 명시했다. 지표 정의 개선은 v1.x 우선순위 1이다([v1x-backlog.md](v1x-backlog.md)). 가중치 기본값은 3개 시드의 검증 결과에 맞춰 조정하지 않았다(과적합 방지). 순위표의 가중치 슬라이더로 IBS 그룹을 낮출 수 있다.
- 출시를 막을지 여부는 연구실이 결정한다. 점수의 용도를 제한해 표시하는 조건으로 v1.0 출시 점검을 진행했다.

**M3-2 설계 후보 품질 회귀** ([regression-baseline.md](regression-baseline.md), `tests/regression/`): 후보 20개, 최대 변이 8, 난수 시드 1에서 품질 후보(pLDDT ≥ 80, RMSD ≤ 2 Å) 비율 TmAFP 100%, Type I 95%, Type III 65%. PRD 목표 30% 이상을 모두 통과한다. 회귀 테스트는 기준선에서 ±5%p를 벗어나면 실패한다(후보 20개에서 1개 = 5%p).

**M3-3 내보내기** (`afp/export/exporter.py`, CLI `export`, 순위표 페이지의 내보내기·ZIP 다운로드): 위 형식대로 `candidates.fasta`(첫 항목 시드 원본), `ranking.csv`, `structures/`, `seed.json`, `params.json`, `versions.json`, `scoring.json`, `README.txt`(점수 한계 문구, 재현 명령), `manifest.json`을 만든다. 기존 폴더는 덮어쓰지 않는다(UI는 덮어쓰기 허용). 통합 테스트로 확인했다.

**M3-4 실험팀 전달 패키지:** 형식과 권장 대조군·측정 항목은 내보내기 `README.txt`에 들어 있다. 실제 전달은 하지 않았다(실험팀과 대조군, 측정 항목, 일정 합의가 필요).

**M3-5 문서화:** [README.md](../../README.md), [user-guide.md](../user-guide.md), [ops.md](../ops.md).

**M3-6 사용성 테스트:** 사람 참여자가 필요해 하지 못했다. 대신 시나리오 1을 UI만으로 끝까지 수행하는 자동 테스트(Streamlit AppTest, `test_scenario_1_end_to_end_through_the_ui`)로 흐름이 끊기지 않음을 확인했다. 이는 사용성 검증이 아니다. 신규 연구원 1명이 설명서 없이 시나리오 1을 완료하는지는 출시 전에 관찰해야 한다.

## 열린 문제 (답)

- 양성 대조 검증 결과와 지표 정의 변경 이력: 불합격(실험 0/3, 예측 1/3). 지표 정의는 v1에서 바꾸지 않았다. 변경 이력 없음.
- 설계 후보 품질 비율과 PRD 목표 대비 차이: 65~100%로 목표(30%)보다 높다. 이유는 시드와 후보의 서열 차이가 작고(최대 8개 치환, IBS 밖) ESMFold가 변이를 잘 받아들이기 때문으로 보이며, 구조 품질이 활성을 보장하지는 않는다.
- 실험팀과 합의한 대조군, 측정 항목, 전달 일정: 미정. 패키지 형식은 준비됨.
