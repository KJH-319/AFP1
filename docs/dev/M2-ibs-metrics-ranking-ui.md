## IBS 지표 정의 (M2-1)

모든 지표는 **예측된 후보 구조**와 시드의 IBS 잔기 번호로 계산한다. 아래 정의는 출발점이며, M3의 양성 대조 검증에서 변별력을 확인하고 필요하면 조정한다. 조정할 때는 변경 이유를 이 문서에 남긴다.

| 지표 | 정의 | 방향 |
| --- | --- | --- |
| `ibs_planarity` | IBS 잔기의 대표 원자(Thr·Ser는 Oγ, 그 외는 Cβ, Gly는 Cα) 좌표에 최소제곱 평면을 맞추고 평면으로부터의 RMS 거리(Å)를 구한다 | 낮을수록 좋음 |
| `ibs_area` | IBS 잔기의 용매 접근 표면적 합(Å², freesasa) | 높을수록 좋음 |
| `ibs_lattice_dev` | IBS의 극성 대표 원자 쌍 중 거리가 3~10 Å인 쌍마다, 얼음 격자 간격(4.52 Å, 7.35 Å)과 그 2배 중 가장 가까운 값과의 편차를 구해 평균한다(Å). 쌍이 없으면(예: Type I의 Thr 간격 약 16 Å) 계산하지 않고 점수에서 제외한다 | 낮을수록 좋음 |
| `ibs_hydrophobic_frac` | IBS 잔기 중 소수성 잔기(A, V, L, I, M, F, W, C)의 비율 | 시드 값과의 차이가 작을수록 좋음 (방향 고정 안 함) |

- 후보와 시드의 IBS 잔기 번호는 같다(치환만 지원하므로 위치가 변하지 않는다).
- 구조 예측이 실패했거나 IBS 영역 pLDDT가 임계값 미만인 후보는 지표를 계산하되 `flags`에 `low_ibs_confidence`를 붙인다.

## 무작위 패치 기준선 (M2-2)

IBS 지표가 "진짜 IBS여서" 좋은 값인지, 아무 표면 패치나 비슷한 값을 내는지 구분하기 위한 기준선이다.

- 시드 구조에서 IBS와 같은 잔기 수(`k`)의 표면 패치를 무작위로 N개(기본 100, 제안값) 뽑아 같은 지표를 계산한다. 패치는 표면에서 서로 가까운 잔기 `k`개로 만든다.
- 이 분포의 중앙값을 음성 앵커(`x_neg`)로, 시드의 실제 IBS 값을 양성 앵커(`x_seed`)로 쓴다.
- 비-AFP 대조 단백질에서도 같은 방식으로 무작위 패치 분포를 만든다(M3 검증에서 사용).

## AFP 유사도 (M2-3)

- `esm_llr`: 변이 위치에서 `log p(후보 아미노산) − log p(시드 아미노산)`의 합(마스킹 확률 기준). M1의 위치별 점수를 재사용한다.
- `seq_identity`: `1 − n_mut / 길이`.
- 이 점수는 "시드에서 얼마나 멀어졌고 모델이 그 변화를 얼마나 받아들이는가"를 나타낼 뿐, AFP 활성의 직접 지표가 아니다. UI 설명에도 그대로 쓴다.

## 개발성 필터 (M2-4)

플래그만 붙이고 후보를 자동 삭제하지는 않는다. 사용자가 필터로 숨길 수 있다.

| 항목 | 방법 |
| --- | --- |
| 순전하, pI | Biopython `ProteinAnalysis` |
| 소수성 패치 | 후보 구조에서 노출된 소수성 잔기(A, V, L, I, M, F, W)의 SASA가 전체 SASA에서 차지하는 비율이 **시드보다 10%p 넘게 늘면** `hydrophobic_patch` (절대 기준은 시드마다 달라 상대 기준을 쓴다) |
| N-글리코실화 서열 | `N-X-S/T`(X는 Pro 제외) 탐지, 발현 숙주가 효모이면 의미가 있어 `n_glyc` |
| 비정상 Cys | 쌍을 이루지 않는 홀수 개의 Cys는 `odd_cys`. 시드가 원래 이황화결합을 가지면 개수를 시드와 비교 |
| 중복 제거 | 완전 일치와 해밍 거리 기준. MMseqs2는 선택 |

## 종합 점수 (M2-5)

각 지표를 시드와 음성 앵커 사이로 정규화한 뒤 가중합한다.

```
norm_i = clip((x_i − x_neg) / (x_seed − x_neg), 0, 1.2)     # 방향이 반대인 지표는 부호를 뒤집는다
score  = Σ w_i · norm_i
```

- 그룹별 기본 가중치(제안값, M3 검증으로 확인): 구조 신뢰도 0.3, IBS 0.4, AFP 유사도 0.2, 개발성 0.1. 합은 1로 정규화한다.
- 구조 신뢰도 그룹은 `plddt_mean`과 `rmsd_seed`, IBS 그룹은 4개 지표의 평균, 개발성 그룹은 플래그 개수 기반 감점이다.
- 순위는 `score` 내림차순이다. Pareto 순위는 v1.x다.
- 가중치와 앵커 값은 `candidates.csv`와 같은 폴더의 `scoring.json`에 기록해 재현할 수 있게 한다.

## 순위표 페이지 (M2-6)

- 표: `st.dataframe`에 열 설정을 적용해 순위, 점수, 주요 지표, 플래그를 보여준다.
- 사이드바: 가중치 슬라이더 4개(바꾸면 순위가 즉시 갱신), pLDDT·RMSD 임계값, 개발성 플래그 숨김 체크박스.
- 3D 뷰어(stmol 또는 py3Dmol): 시드를 회색, 선택한 후보를 색으로 겹쳐 보여주고 IBS 잔기를 스틱으로 강조한다. 한 번에 2~4개까지.
- 모든 점수 화면 상단에 고정 문구: "우선순위 보조 지표이며 실제 TH 예측이 아닙니다."
- 후보를 체크해 내보내기 선택 목록에 담는 기능까지만 넣고, 내보내기 자체는 M3에서 구현한다.

## 구현 기록 (2026-10-12)

**구현 범위:** F-8, F-9, F-10, F-11, F-12 전부. 모듈은 `afp/evaluate/{ibs_metrics,developability,scoring}.py`, UI는 `app/pages/2_Ranking.py`다.

**정의에서 달라지거나 구체화한 것**

- 기준 구조: 앵커(시드 IBS 값, 무작위 패치 분포)는 후보와 같은 방식인 **시드 서열의 ESMFold 예측 구조**에서 계산한다(실험 구조와 예측 구조를 섞으면 편향된다). 예측기가 없으면 실험 구조를 쓰고 `scoring.json`의 `reference_structure`에 기록한다.
- 격자 편차는 3~10 Å 쌍만 보고(위 표 참고), 쌍이 없는 시드(Type I의 Thr 간격 약 16 Å)는 계산하지 않아 `degenerate`로 점수에서 제외한다. 주기가 긴 IBS를 다루려면 격자 허용 거리를 늘려야 하며 v1.x 과제다.
- 소수성 비율은 방향을 가정하지 않고 "시드와 가까울수록 좋음"으로 정규화한다. 나머지 세 지표는 시드 값(1)과 음성 앵커(0) 사이로 선형 정규화하고 최대 1.2까지 인정한다.
- 그룹 점수: 구조 = (pLDDT 정규화 + RMSD 정규화)/2, AFP = (로그비 정규화 + 서열 동일도)/2, 개발성 = 1 − 0.25×(개발성 플래그 수), IBS = 사용 가능한 지표 정규화값의 평균. IBS 지표를 모두 계산할 수 없으면 IBS 그룹을 빼고 나머지 가중치를 재정규화한다. 상수는 `afp/config.py`에 있다.
- 구조 예측 실패 후보는 점수 없이 순위 맨 뒤다. `near_duplicate`는 점수에 영향을 주지 않고 순위가 낮은 쪽에만 붙는다.
- 3D 뷰어: `stmol` 대신 `py3Dmol`을 직접 쓴다. 후보를 시드 Cα에 Kabsch 정렬해 겹친다. 3Dmol 스크립트는 CDN에서 불러온다.

**관찰**

- 실제 모델로 Type III 시드를 돌린 결과(후보 8개), 후보의 IBS 지표는 시드와 거의 같아(g_ibs 0.86~1.09) 순위의 대부분이 구조 신뢰도와 ESM 로그비에서 나온다. 모드 A가 IBS를 바꾸지 않으므로 예상된 결과다. UI와 사용자 가이드에 이 사실을 적었다.
- 양성 대조 검증(M3)에서 평면성만 일관되게 변별되었다. 자세한 내용은 [validation-report.md](validation-report.md).

## 열린 문제 (답)

- 무작위 패치 기준선의 패치 수와 `k` 설정이 안정적인지: 기본 100개, `k` = 시드 IBS 크기(4~9)로 두었다. 패치 수에 따른 앵커(중앙값)의 안정성은 따로 측정하지 않았다. IBS가 4~5잔기로 작은 시드는 패치 분포가 넓어(예: Type III 평면성 p10~p90 = 0.51~1.65 Å) 앵커의 불확실성이 클 것으로 보이며, 패치 수 민감도 측정은 v1.x에서 한다.
- 변별력이 없어 제외하거나 정의를 바꾼 지표: v1에서는 정의를 바꾸지 않았다(검증 결과를 보기 전에 정한 기준을 지키기 위해). 면적은 방향 가정이 반대로 나왔고, 격자 편차는 시드에 따라 일관되지 않았다. 개선은 v1.x 우선순위 1([v1x-backlog.md](v1x-backlog.md)).
- 3D 뷰어 라이브러리 선택과 이유: `py3Dmol` 직접 사용. `stmol`은 구버전 ipywidgets 의존성 때문에 최신 Python 환경에서 임포트가 실패했다.
