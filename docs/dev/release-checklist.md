# v1.0 출시 점검 (M3-7)

PRD 6장의 출시 기준을 항목별로 점검한 결과다. 점검일 2026-10-12. 상태: ✅ 충족 · ◐ 부분 충족 · ❌ 미충족.

## 요약

**기술 기준은 충족했지만 두 가지가 남아 있다: 양성 대조 검증이 불합격이고, 사람이 필요한 확인(사용성 테스트, 실험 전달, 시드 IBS 전문가 확인)을 하지 못했다.** 점수의 용도를 "후보 선별용 보조 지표"로 제한해 표시하는 조건으로 사내 시험 사용을 시작할 수 있고, 정식 v1.0 선언 여부는 연구실이 결정한다.

## 테스트 현황

최종 실행(2026-10-12, Windows 11, RTX 3050 6GB, ESMFold는 CPU):

| 명령 | 결과 |
| --- | --- |
| `python -m pytest` (단위·통합·UI, 모델 가중치 불필요) | 95 통과, 약 42초 |
| `python -m pytest -m "gpu or regression"` (실제 ESM-2·ESMFold) | 9 통과, 약 11분. 회귀 테스트가 기준선(TmAFP 100%, Type I 95%, Type III 65%)을 실제 모델로 다시 재현 |
| `python -m afp.check` | 8/8 통과 |

단위 테스트는 불변식(IBS 고정, 길이 동일, 변이 수 상한, Gly/Pro/Cys 불변), 기하 지표(평면성, 격자 편차), 정규화와 가중합의 경계값·단조성, 개발성 규칙, 파서 오류 처리, 상태 파일 원자성을 다루고, 통합 테스트는 서브프로세스 실행·취소·실패·재현성, 내보내기, 세 UI 페이지를 다룬다.

## 출시 전 남은 일 (사람 필요)

1. 신규 연구원 1명 이상이 설명서 없이 시나리오 1을 완료하는지 관찰 (사용성 테스트).
2. 홈의 새 시드 등록(PDB/FASTA 업로드)을 브라우저에서 수동 확인.
3. `type1_hplc6`(derived)과 `tmafp_beetle`(literature_partial)의 IBS 잔기를 전문가가 문헌으로 확인.
4. 실험팀과 대조군, 측정 항목, 전달 일정을 합의하고 상위 후보 패키지를 전달.
5. 양성 대조 검증 불합격을 고려해 정식 v1.0 선언 여부를 연구실이 결정.
6. 사내 서버에 배포한다면 `pip-licenses` 점검, 방화벽 설정, GPU(14GB 이상이면 ESMFold GPU 실행) 확인.
