## 착수 전 확인할 것

- **모드 B:** RFdiffusion은 자체 환경이 필요할 수 있어 별도 conda 환경 또는 컨테이너로 분리하는 방안을 검토한다. GPU VRAM이 충분한지 먼저 확인한다.
- **간이 MD:** 얼음 슬랩 설정과 힘장 선택이 결과를 좌우한다. 양성 대조에서 결합이 관찰되지 않으면 본 작업에 들어가지 않는다. 비용 대비 효과를 착수 시 다시 평가한다.
- **점수 보정:** 실험 결과가 5개 안팎이면 통계적 결론을 내기 어렵다. 순위가 크게 어긋나는 후보를 개별 분석하는 용도로 쓴다.
