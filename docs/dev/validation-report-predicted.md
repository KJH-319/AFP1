# 양성 대조 검증 보고서 (M3-1)

**판정: 불합격** (시드 1/3개 통과)

알려진 AFP 시드의 IBS 지표가 비-AFP 단백질의 같은 크기 무작위 표면 패치와 구분되는지 확인한 예비 검증이다. 시드가 3개뿐이라 통계 검정 대신 순위 분리로 판정했고, 결과를 일반화하기에는 표본이 작다.

## 설정

- 구조: predicted · 무작위 패치 수: 시드당 100개(음성 대조 단백질마다) · 난수 시드: 1
- 음성 대조: bpti, gcn4_zipper, ubiquitin
- 판정 기준(결과를 보기 전에 정함): 방향성 지표(평면성↓, 격자 편차↓, IBS 면적↑) 3개 중 2개 이상에서 시드 IBS가 대조 패치의 90% 이상보다 얼음 결합면다움. 모든 시드 통과 = 합격, 절반 이상 = 부분 합격, 그 미만 = 불합격. 소수성 비율은 방향을 가정하지 않아 참고만 한다.

## 해석 시 주의

- 이 검증은 IBS **지표**가 시드의 IBS와 무작위 패치를 구분하는지만 본다. 설계 후보의 실제 얼음 결합 활성은 검증하지 않는다.
- 근거 수준이 `derived`나 `literature_partial`인 시드는 IBS 잔기 목록 자체가 불완전할 수 있어 결과 해석에 주의한다.
- Type I처럼 IBS 잔기 사이 거리가 격자 쌍 범위(3~10 Å)를 벗어나는 시드는 격자 편차를 계산할 수 없다(NaN).
- 지표 정의를 바꾸면 이 보고서를 다시 만들고, 변경 이유를 docs/dev/M2-ibs-metrics-ranking-ui.md에 남긴다.
